# Dentist Fit Quiz (Reflections Dental Group)

Self-hosted lead-gen quiz for Reflections Dental Group, Calgary. Single static page,
no build step. Leads POST to the existing `reflections-quiz-relay` Cloudflare Worker
with `quiz_id: reflections-dentist-fit`.

**This is a client project, separate from the Kaizen quiz fleet.**

- Live page: https://jameson-kaizen.github.io/reflections-dentist-fit-quiz/
- Ops doc: `Dentist-Fit-Quiz/SELF-HOST.md` in the project folder (not this repo)

The four pattern guides are served from `guides/` and linked from each results page.

General information about choosing dental care. Nothing here characterises another
practice. See the project `docs/TRAPS.md` T2.
